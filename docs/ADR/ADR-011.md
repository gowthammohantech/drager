# ADR-011: Interrupted transfers restart; resume is P1

Status: Accepted

## Context
AD §7: resume needs authenticated state revalidation.

## Decision
On disconnect, cancel or hash mismatch the receiver deletes the staging `.sbpart` file and records a terminal outcome. The sender surfaces a Retry action that creates a new transfer ID. Offsets and PROGRESS acks are already on the wire so resume can be added without a protocol bump. Stale staging files older than 24 h are purged at launch.

## Consequences
Large transfers over flaky Wi-Fi restart from zero.
