# ADR-016: Sign with the paid individual team for App Store Connect

Status: Accepted (supersedes the signing team in ADR-009)

## Context
ADR-009 chose the free Personal Team `TWR2VXDJQB`. Free teams can't upload to App Store Connect, so TestFlight and App Store distribution are impossible with it.

## Decision
- Default `DEVELOPMENT_TEAM` is `F25JAA3QPD` ("Gowtham Mohan", Individual, paid Apple Developer Program). Signing stays automatic.
- Version for the first TestFlight build is `1.0.0 (1)`.
- iOS ships through App Store Connect with `Scripts/archive-ios.sh`. macOS keeps Developer ID distribution (`Scripts/archive-macos.sh`).

## Consequences
- Contributors without access to `F25JAA3QPD` override it with `SB_DEVELOPMENT_TEAM` in `Config/Local.xcconfig`.
- Bump `CURRENT_PROJECT_VERSION` in `Config/Shared.xcconfig` before every upload; App Store Connect rejects a repeated build number.
