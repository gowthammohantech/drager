# ADR-001: Network.framework as the primary transport

Status: Accepted

## Context
MultipeerConnectivity is deprecated (BRD research). We need TLS, Bonjour and fine-grained backpressure.

## Decision
Use `NWListener` / `NWBrowser` / `NWConnection` (classic API, available on iOS/macOS 26) wrapped in actors and exposed through `FrameTransport`, `PeerDiscovering` and `PeerListening` protocols in `BridgeCore`. MPC is not used.

## Consequences
Swapping to the newer `NetworkConnection` API or a WebSocket adapter later only touches `BridgeNetworking`.
