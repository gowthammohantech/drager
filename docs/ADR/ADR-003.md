# ADR-003: Separate control DTOs from the binary data plane

Status: Accepted

## Context
FRD §4 forbids large `Data` in JSON; memory must stay bounded for 100 MiB files.

## Decision
Frames: 1-byte type + 4-byte big-endian length. Type 0x01 carries a JSON `ControlMessage` (≤64 KiB). Type 0x02 carries a chunk header (UUID, sequence, offset) plus ≤512 KiB raw bytes. The header is validated against limits before any allocation. See `docs/API/PROTOCOL.md`.

## Consequences
Malformed or oversized frames close the connection with E012.
