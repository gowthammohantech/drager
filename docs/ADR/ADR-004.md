# ADR-004: Manual spatial calibration

Status: Accepted

## Context
BLE RSSI and Wi-Fi cannot determine physical arrangement (BRD research, AD §9).

## Decision
The user picks phone placement (below/above/left/right), Mac display, alignment offset and mirroring. `SpatialLayout` + `CoordinateMapper` map the iPhone exit edge and normalized position to the Mac arrival edge and point.

## Consequences
Calibration is a user preference; we never claim sensed positioning.
