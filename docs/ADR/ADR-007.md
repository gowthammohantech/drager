# ADR-007: One concurrent transfer, bounded backpressure

Status: Accepted

## Context
FRD §4 limits MVP to one transfer; memory must stay bounded.

## Decision
Each session runs at most one transfer. The sender awaits `.contentProcessed` on each send and keeps at most `sendWindow` (4) chunks in flight; the receiver writes each chunk before reading the next.

## Consequences
Peak memory ≈ window × chunk size (≈1–2 MiB) independent of file size.
