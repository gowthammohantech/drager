# ADR-007: One concurrent transfer, bounded backpressure

Status: Accepted

## Context
FRD §4 limits MVP to one transfer; memory must stay bounded.

## Decision
Each session runs at most one transfer. The sender awaits `.contentProcessed` for each chunk before reading the next one from disk; the kernel's TCP send buffer provides the pipelining. On the receiver, frames pass through an 8-frame bounded inbox. When disk writes lag, the read loop pauses, stops reading from the socket, and TCP flow control throttles the sender.

## Consequences
Peak memory ≈ window × chunk size (≈1–2 MiB) independent of file size.
