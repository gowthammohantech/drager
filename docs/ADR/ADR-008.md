# ADR-008: Overlay is a best-effort visual layer

Status: Accepted

## Context
Full-screen apps, Stage Manager and Spaces can obscure windows (BRD risk table).

## Decision
A non-activating, click-through `NSPanel` at `.statusBar` level joins all Spaces including full-screen. If the overlay is disabled or no display is available, a `UNUserNotification` is posted instead (FR-210).

## Consequences
Success is only ever shown after COMMITTED, regardless of the presentation path.
