# ADR-005: User-selected destination with security-scoped bookmark

Status: Accepted

## Context
The sandboxed Mac app has no implicit Desktop access (BRD research, TD §9).

## Decision
`NSOpenPanel` directory selection → app-scoped security-scoped bookmark persisted in UserDefaults. On stale/failed resolution the user is re-prompted (FR-207, T-08). Desktop is only a suggested starting location.

## Consequences
Receiving is blocked with E009 until a folder is chosen.
