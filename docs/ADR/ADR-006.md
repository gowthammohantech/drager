# ADR-006: Native SwiftUI + AppKit, one SPM package with many targets

Status: Accepted

## Context
The prompt suggested one package per module; nine separate packages add manifest churn without isolation benefits.

## Decision
`Packages/SpatialBridgeKit/Package.swift` declares one target per module (BridgeModels, BridgeCore, …) with explicit dependencies, so module boundaries are still compiler-enforced. Packages import only Foundation/CryptoKit/Network/CoreGraphics/UniformTypeIdentifiers/os. The package lives under `Packages/` (not the repo root) so Xcode does not treat the repo as a package.

## Consequences
Platform UI lives exclusively in the two apps.
