# ADR-010: Pairing: SAS-authenticated X25519, sessions over TLS 1.3 external PSK

Status: Accepted

## Context
FRD §5 requires authenticated key exchange with an out-of-band short code and encrypted sessions, without custom primitives or permissive trust callbacks.

## Decision
First contact runs over plain TCP: HELLO ↔ HELLO, PAIR_REQUEST (X25519 ephemeral + Ed25519 key + challenge) → PAIR_RESPONSE (same + transcript signature). Both sides derive SAS/PSK/confirm keys with HKDF-SHA256 salted by the transcript hash. Users compare a 6-digit SAS; each side sends PAIR_CONFIRM (HMAC over role and approved peer; the initiator also signs the transcript). Trust is persisted only when the local user approved and the peer's confirmation verified. Failures are rate-limited (3 per 60 s). Subsequent sessions use TLS with the 32-byte pair PSK (`sec_protocol_options_add_pre_shared_key`, identity = initiator peer ID); the listener registers one PSK per trusted peer and an unknown identity fails the handshake (T-11).

**Feasibility spike (2026-10-21, Xcode 27 SDK, loopback):** TLS 1.3 external-PSK-only handshakes fail in Network.framework (`-9858 handshake failed`) for every combination tried. TLS 1.2 PSK works. The server picks the right key among several by identity, an unknown identity fails with `-9864`, and a wrong key fails with a bad MAC. We therefore pin TLS 1.2 with the single suite `TLS_ECDHE_PSK_WITH_CHACHA20_POLY1305_SHA256` (0xCCAC): AEAD plus ECDHE forward secrecy. Resumption, tickets and renegotiation are disabled.

**Session binding:** Network.framework does not tell the server which PSK identity a client used, so after TLS each side sends `SESSION_AUTH`. This is an Ed25519 signature over both fresh HELLO nonces, both peer IDs and the signer's role, verified against the key stored at pairing. A trusted peer therefore cannot impersonate another trusted peer, and signatures can't be replayed across sessions.

**Pairing transport:** pairing runs on a separate plain-TCP listener, advertised as a second `_spatialbridge._tcp` instance with TXT `role=pairing`, and only while pairing is enabled on the Mac.

## Consequences
The SAS is never key material. A MITM must guess the SAS (1 in 10⁶ per attempt, rate-limited).
