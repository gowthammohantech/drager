# ADR-012: Hand-written Xcode projects, no generator

Status: Accepted

## Context
No XcodeGen/Tuist is installed; adding a generator would be a new mandatory developer dependency.

## Decision
Both `.xcodeproj` files use Xcode 16+ file-system-synchronized folders, so adding source files needs no project edits. App build settings live in `Config/*.xcconfig`; project files only reference them and the local package.

## Consequences
Project files stay small and rarely change; Xcode may rewrite them to objectVersion 110 on save, which is fine.
