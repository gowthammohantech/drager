# ADR-009: Environment decisions taken autonomously

Status: Accepted

## Context
The original agent could not reach the user for these choices; all are trivially changeable in `Config/*.xcconfig`.

## Decision
Signing team TWR2VXDJQB (automatic). Minimum iOS 26.0 / macOS 26.0. Bundle IDs `com.gowthammohan.spatialbridge.ios` / `.mac`. macOS app sandboxed with hardened runtime (works for direct Developer ID and Mac App Store). Branch `feature/spatial-bridge-mvp`, never pushed by the agent.

## Consequences
Override the team via `Config/Local.xcconfig` (`SB_DEVELOPMENT_TEAM`).
